# Mutual Fund FAQ Assistant — pinned runtime dependencies.
# Final set as of Phase 6; verified on Python 3.12.10 / Windows 10 22H2 (x64),
# CPU-only. Every third-party import in the codebase resolves to one of these
# pins, and Phase 6 asserts that (SC-12, SC-14).
#
# Install:
#   python -m venv .venv
#   .venv\Scripts\python.exe -m pip install -r requirements.txt
#
# WHY torch is pinned explicitly and sourced from the PyTorch CPU index:
#   1. The default PyPI torch wheel is the large CUDA build, which a CPU-only
#      prototype does not need.
#   2. The +cpu build exists only on the PyTorch index, hence --extra-index-url.
#   3. Streamlit Community Cloud's PyTorch index no longer publishes a wheel for
#      the 2.5.x line, so the CPU pin moves to a version it does serve:
#      torch==2.9.0+cpu. The `+cpu` local label is kept (rather than dropping it
#      for a base version) because this is the exact version the Cloud index
#      lists. No application code depends on a specific torch build — the
#      embedding model, ChromaDB, retrieval, guardrails, Groq, memory, and the
#      Streamlit UI are all unchanged — so the only effect is the installed
#      torch version.

--extra-index-url https://download.pytorch.org/whl/cpu
